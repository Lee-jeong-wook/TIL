# 자바 프로그램 실행 흐름
1. java 파일이 javac에 의해 컴파일되어 바이트코드로 변환, class파일 생성
2. 클래스 로더가 JVM에 동적 로드
> 런타임 시점에 필요한 클래스만 로드하는 것
3. 로딩 및 링킹, 이니셜라이징
> 로딩: 클래스 파일 JVM에 로드, Method area <br>
> 링킹: 로드된 클래스가 실행될 수 있도록 준비하는 단계<br>
> 초기화: static 변수를 사용자가 지정한 값으로 초기화하고 static 블록을 실행하는 단계
4. 인터프리터와 JIT 컴파일러를 통해 기계어 변환 이후 실행 엔진에서 실행
> 인터프리터는 초기 실행속도, JIT는 캐싱으로 인한 반복 코드 실행 속도, 그래서 JAVA는 둘 다 사용
